# Customer Churn Analysis

## Project Overview

This project analyzes customer churn data to identify patterns influencing customer retention and provides data-driven business recommendations.

## Business Problem

Customer churn reduces company revenue and impacts long-term profitability. This project helps identify high-risk customers and recommends strategies to improve retention.

## Objectives

- Analyze customer behavior
- Identify churn factors
- Generate business insights
- Provide actionable recommendations

## Dataset

- Customer Churn Dataset
- 500 Rows
